## 🎯 About iGram.ink

**iGram.ink** is a free, fast, and secure **Instagram video downloader** that lets you save **Instagram Reels**, **videos**, **photos**, **Stories**, **IGTV**, and **carousel posts** directly to your device. No login required, no watermarks, and no download limits.

Built as an alternative to **igram.world**, **snapinsta**, **savefrom**, and **instasave**, iGram.ink focuses on:

- ⚡ **Blazing fast downloads** using the Cobalt API
- 🎨 **Clean, modern UI** built with Tailwind CSS
- 🔒 **Complete privacy** — no tracking, no login, no data storage
- 📱 **Full device support** — mobile, tablet, desktop
- 💯 **100% free forever** — no premium tiers, no hidden fees

Whether you want to **download Instagram Reels without watermark**, **save Instagram photos to your phone gallery**, or **archive IGTV videos for offline viewing**, iGram.ink is your go-to solution.

## 🛠️ Tech Stack

### Frontend
- **HTML5** — Semantic markup
- **Tailwind CSS** — Utility-first styling via CDN
- **Vanilla JavaScript** — No frameworks, fast and lightweight
- **Font Awesome 6** — Icons
- **Google Fonts** — Inter & Plus Jakarta Sans

### Backend / API
- **Cobalt API** — Open-source media downloader
- **Self-hosted option** — Docker deployment for production
- **Public API** — `api.cobalt.tools` for testing only

### SEO & Performance
- **Schema.org** structured data (WebApplication, FAQPage, BlogPosting)
- **Open Graph** & **Twitter Cards** for social sharing
- **Sitemap.xml** & **robots.txt** for search engine crawling
- **Lazy loading** for images
- **CDN-hosted assets** for fast global delivery
